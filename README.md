# simple-business-management-program
Hi, I’m a student in systems, networks, and telecommunications. I wanted to code something simple, so I built a management tool for those who don’t have the budget for expensive, large-scale software. Thanks!

I also wanted to mention that this is a modular program, so you’ll need a main folder containing subfolders; within each subfolder, you’ll find header files and source files. Make sure to organize them properly before compiling the code, guys—thanks again!
